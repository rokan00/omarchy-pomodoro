# omarchy-pomodoro

A Pomodoro timer plugin for Omarchy's Quickshell-based bar (`omarchy-shell`),
placed in the center of the bar and fully theme-compatible via Omarchy's
`Color.*`/`Style.*` design tokens.

This scaffold will be filled in by a scheduled Claude Code cloud agent run.
See the plugin directory `mlhunter.pomodoro/` once the build completes.
